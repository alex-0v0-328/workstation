# Workstation 0.8.2

本地优先的 Windows 11 x64 桌面应用。SQLite 持有学期、课程、考核、手动任务、课表事件、设置和邮件摘要进度。一个 Gmail 账号；没有应用账号或云同步。

## 已确认行为

- TODO 页签：今天 / 有DDL / 日常 / 已完成 / 已归档；有DDL 再分今天 / 未来七天 / 全部。列表按「学业 / 生活」分组，未公布时间的学业考核归入「待排期」，永不进入「日常」（考核仍是唯一数据源，不产生可编辑副本）。新建为单一对话框，用「日常」（默认，无截止日期）/「有DDL」类型卡片切换。「归档已完成」批量归档时保留已记录成绩的考核。完成状态与成绩和 hurdle 状态独立。
- 学期和课程由用户定义。日期可能未知或仅日期。考核类型可扩展。权重和分数可选；无隐式缩放或及格预测。
- Hurdle 保留原始要求，支持人工确认和可选的考核关联。
- 课表接受 ICS 文件、订阅 URL 和手动事件。导入前预览。外部 HTML 页面作为链接，不抓取。周课表按时间比例排布（基准 08:00–20:00，随课程延展），重叠课程并排分栏。
- 内置主题仅 Windows 11 原生（Mica 毛玻璃、悬浮侧边栏、浅色/深色/跟随系统）。其余主题为可安装的 `.wstheme.json` 主题包。安装包附带三个示例主题，可在“设置 → 外观与桌面”一键安装：Catppuccin（Latte/Frappé/Macchiato/Mocha 四口味）、复古 Windows 95/98（固定经典外观与任务栏布局）和 Cyber 赛博朋克（Acid：纯黑底、荧光黄强调）。主题切换不重置数据与草稿；Mica 材质在系统不支持时自动降级为实色。
- Gmail 只读，经 IMAP + 应用专用密码连接（无需 Google Cloud 配置）。邮件内容不可信。DeepSeek 翻译单封邮件；每日到设定时间自动总结过去 24 小时（昨日设定时间到今日设定时间）的收件箱邮件，手动触发则总结今天 00:00 至今的邮件（均含已读）。不包含附件。默认模型 `deepseek-flash`。邮件列表缓存优先：先显示本机快照再联网刷新。
- 界面语言支持简体中文（默认）、繁體中文、English；界面字体可选 Windows 默认、苹方 (PingFang SC)、SF Pro、CaskaydiaCove Nerd Font，与主题独立。
- 「后台运行」开关（默认开）：关闭窗口驻留托盘继续提醒与总结；关闭后叉掉窗口即完全退出。可选开机启动（安装版生效，启动时静默进托盘）。持久化提醒/摘要状态、备份与恢复均属于首次交付范围。恢复后补做遗漏工作。

## 交付顺序

1. 桌面/数据/主题基础与类型化 IPC。
2. 学习向导、可复用模板、TODO、成绩、课表、备份。
3. Gmail IMAP、安全读取、翻译、每日摘要、调度。
4. 自动化测试、UI 检查、安装包、设置与验收文档。

## 默认与边界

一个本地用户、一个 Gmail 账号、中文界面、系统时区、无重复手动任务。学期/课程归档保留历史。主题包可在设置视图中安装和移除。凭据（Gmail 应用专用密码、DeepSeek API key）使用 Windows 支持的 Electron `safeStorage` 加密，只保存在本机，从不导出。备份恢复本地学业/任务/设置数据，并从提供商重新创建缓存。

线上提供商测试需要用户自己的 Gmail 应用专用密码和 DeepSeek key。打包构建不能证明通知投递、IMAP 登录成功或真实课表兼容性。
